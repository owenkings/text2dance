# 镜像配置说明

本文档说明如何通过 `cache_config.txt` 文件配置和使用镜像管理系统。

## 配置位置

镜像配置位于项目根目录的 `cache_config.txt` 文件中。

## 配置文件格式

`cache_config.txt` 使用简单的键值对格式：

```ini
# ==================== 缓存配置 ====================
# 模型文件缓存路径，用于存储下载的模型文件
cache_path=E:\Tiany\huggingface
# 最小可用空间要求（GB），下载前检查磁盘空间
min_free_space_gb=20

# ==================== 模型配置 ====================
# ShareGPT4Video模型路径标识符
sharegpt4video_model_path=Lin-Chen/sharegpt4video-8b

# ==================== 网络配置 ====================
# 网络连接超时时间（秒）
connection_timeout=10
# 下载超时时间（秒）
download_timeout=300
# 启用自动镜像切换
auto_mirror_switch=true

# ==================== 镜像站点配置 ====================
# HuggingFace官方站点
official_site=https://huggingface.co
# 镜像站点列表（按优先级排序，用逗号分隔）
mirror_sites=https://hf-mirror.com,https://modelscope.cn
# 用户自定义镜像站点（可选，用逗号分隔）
custom_mirrors=
```

## 如何修改配置

1. 打开项目根目录的 `cache_config.txt` 文件
2. 使用任何文本编辑器修改相应的配置项
3. 保存文件
4. 重新运行程序使配置生效

## 配置参数说明

### 缓存配置参数

- `cache_path`: 模型文件缓存路径，用于存储下载的模型文件
- `min_free_space_gb`: 最小可用空间要求（GB），下载前检查磁盘空间

### 模型配置参数

- `sharegpt4video_model_path`: ShareGPT4Video模型路径标识符

### 网络配置参数

- `connection_timeout`: 网络连接超时时间（秒）
- `download_timeout`: 下载超时时间（秒）
- `auto_mirror_switch`: 启用自动镜像切换

### 镜像站点参数

- `official_site`: HuggingFace官方站点URL
- `mirror_sites`: 镜像站点列表（按优先级排序，用逗号分隔）
- `custom_mirrors`: 用户自定义镜像站点（可选，用逗号分隔）

## 添加自定义镜像

在 `custom_mirrors` 配置项中添加新的镜像站点URL，多个站点用逗号分隔：

```ini
custom_mirrors=https://my-mirror.example.com,https://another-mirror.com
```

## 配置示例

### 修改缓存路径

```ini
cache_path=D:\MyCache\huggingface
```

### 添加自定义镜像

```ini
custom_mirrors=https://my-mirror.example.com,https://company-mirror.com
```

### 调整网络超时

```ini
connection_timeout=30
download_timeout=600
```

## 优势

✅ **简单易用**: 使用简单的键值对格式，无需复杂的YAML语法  
✅ **用户友好**: 配置文件位于项目根目录，容易找到和编辑  
✅ **灵活配置**: 支持自定义镜像站点和API配置  
✅ **自动切换**: 支持自动镜像切换功能，提高下载成功率  
✅ **即时生效**: 修改配置后重新运行程序即可生效  

## 注意事项

- 修改配置后需要重新运行程序才能生效
- 请确保配置文件格式正确，使用等号分隔键值对
- 自定义镜像的 URL 必须可访问
- 多个镜像站点用逗号分隔，按优先级顺序排列
- Windows路径中的反斜杠会被自动处理，无需转义
- 以 `#` 开头的行为注释，不会被解析
- 关于API配置的注意事项，请参考专门的API配置文档
