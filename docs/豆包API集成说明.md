# 豆包API集成说明

## 概述

本软件已成功集成豆包API，用于视频描述的动作过滤功能。用户可以直接使用，无需额外配置。

## 配置说明

软件已内置豆包API配置，用户可直接使用所有功能，无需配置。同时支持两种不同的自定义配置模式：

### 视频描述API模型
- **内置模型**: 程序内置"火山大模型①"，无需配置即可使用
- **自定义模型**: 用户可在 `cache_config.txt` 中添加自定义API模型
- **使用方式**: 界面中显示所有可用模型（内置+自定义），用户可自由选择
- **配置特点**: 用户无法查看或修改内置模型密钥，只能添加新的自定义模型

### 动作过滤API
- **内置配置**: 程序内置默认API配置，用户无法查看密钥
- **配置覆盖**: 用户填写配置后，程序使用用户的API替代内置API
- **灵活切换**: 删除用户配置后，自动恢复使用内置API
- **配置特点**: 用户可以更改程序实际使用的API，但无法查看内置密钥

**设计理念**: 确保开箱即用的同时，为不同需求提供灵活的配置方案

## 功能特点

### 1. 即开即用
- 无需手动配置API参数
- 软件启动后即可使用动作描述过滤功能
- 自动调用豆包API进行内容处理

### 2. 智能过滤
- 自动识别并保留动作相关描述
- 去除环境、人物衣着等无关信息
- 保持原文表达风格，不进行润色

### 3. 高效处理
- 基于豆包1.5 Pro 32K模型
- 支持长文本处理
- 响应速度快，处理质量高

## 使用方法

### 步骤1：启动软件
```bash
python main.py
```

### 步骤2：打开视频描述功能
1. 在主界面选择"视频描述"功能
2. 勾选"只保留动作描述"选项
3. 上传需要处理的视频文件

### 步骤3：开始处理
1. 点击"开始处理"按钮
2. 系统自动生成视频描述
3. 豆包API自动过滤非动作内容
4. 显示最终的动作描述结果

## 技术实现

### API调用流程
1. 视频描述生成完成后触发过滤
2. 构建豆包API请求（包含prompt和原始描述）
3. 发送POST请求到豆包API端点
4. 解析响应获取过滤后的描述
5. 替换原始描述并保存结果

### 请求格式
```json
{
  "model": "doubao-1-5-pro-32k-250115",
  "messages": [
    {
      "role": "user",
      "content": "帮我处理这段话，只保留动作描述，去除环境、人物衣着相关内容，并且不润色，保证原文：\n\n[原始描述]"
    }
  ],
  "max_tokens": 1000,
  "temperature": 0.1
}
```

## 注意事项

### 1. 网络要求
- 需要稳定的网络连接
- 确保能访问豆包API服务

### 2. 内容替换
- 过滤后的描述会完全替换原始描述
- 原始描述不会被保留
- 如需保留原始描述，建议分两次处理

### 3. 处理时间
- API调用会增加少量处理时间
- 通常在1-3秒内完成

## 故障排除

### 常见问题

**Q: API调用失败怎么办？**
A: 检查网络连接，确认API服务可用性

**Q: 过滤效果不理想？**
A: 可以在配置中调整API参数或更换其他模型

**Q: 如何使用其他API？**
A: 修改 `cache_config.txt` 中的API配置参数

### 错误代码
- `200`: 成功
- `401`: API密钥无效
- `429`: 请求频率过高
- `500`: 服务器错误
