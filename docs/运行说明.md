# 视频编辑应用程序运行和推送说明

## 概述

本项目已完成视频编辑模块的开发，包括完整的视频编辑界面、视频列表管理、预览播放、快捷键操作等功能。

## 运行方式

### 方式一：直接运行主程序

在项目根目录下打开命令提示符或PowerShell，执行：

```bash
python main.py
```

或者使用Python启动器：

```bash
py main.py
```

### 方式二：使用批处理脚本（推荐）

双击运行 `run_and_push.bat` 文件，该脚本会：
1. 自动运行主程序
2. 如果运行成功，自动推送代码到远端仓库
3. 显示详细的执行状态

### 方式三：使用PowerShell脚本

右键点击 `run_and_push.ps1` 文件，选择"使用PowerShell运行"，或在PowerShell中执行：

```powershell
.\run_and_push.ps1
```

### 方式四：测试模块导入

如果主程序无法运行，可以先运行测试脚本检查模块是否正常：

```bash
python test_imports.py
```

## 主要功能

### 视频编辑模块 (VideoEditWidget)

- **视频列表管理**：添加、删除、重新排序视频文件
- **视频预览**：实时预览选中的视频文件
- **播放控制**：播放、暂停、停止、进度控制
- **快捷键支持**：
  - `Space`：播放/暂停
  - `Delete`：删除选中视频
  - `Ctrl+A`：全选视频
  - `F11`：全屏播放
- **编辑操作面板**：提供各种视频编辑功能的快速访问

### 界面集成

- 已将视频编辑模块集成到主窗口的"视频编辑"标签页
- 保持与现有界面风格的一致性
- 支持配置管理和主题切换

## 故障排除

### 常见问题

1. **模块导入错误**
   - 运行 `test_imports.py` 检查依赖
   - 确保所有必要的Python包已安装

2. **Qt应用程序错误**
   - 检查PyQt5是否正确安装
   - 确保显示环境支持GUI应用程序

3. **Git推送失败**
   - 检查网络连接
   - 验证远程仓库配置
   - 确保有推送权限

### 依赖要求

- Python 3.7+
- PyQt5
- opencv-python
- requests
- 其他项目依赖（见 requirements.txt）
