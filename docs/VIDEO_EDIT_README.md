# 视频编辑模块使用说明

## 功能概述

本视频编辑模块提供了完整的视频管理和编辑功能，包括：

### 1. 视频列表管理
- **添加视频**：支持批量添加多种格式的视频文件（MP4、AVI、MOV、MKV、WMV、FLV）
- **删除视频**：可以从列表中删除不需要的视频文件
- **视频信息显示**：自动显示视频文件名和时长信息

### 2. 视频预览和播放控制
- **双击预览**：双击视频列表中的条目即可加载预览
- **播放控制**：提供播放、暂停、停止按钮
- **进度控制**：可拖拽进度条跳转到指定位置
- **时间显示**：实时显示当前播放时间和总时长

### 3. 快捷键支持
- **空格键**：播放/暂停切换
- **左箭头**：向后跳转30帧
- **右箭头**：向前跳转30帧
- **Home键**：跳转到开始位置
- **End键**：跳转到结束位置
- **Ctrl+X**：剪切
- **Ctrl+C**：复制
- **Ctrl+V**：粘贴
- **Delete键**：删除

### 4. 编辑操作面板

#### 基本操作
- **剪切**：剪切选中的视频片段
- **复制**：复制选中的视频片段
- **粘贴**：粘贴视频片段
- **删除**：删除选中的视频片段

#### 时间轴操作
- **分割**：在当前位置分割视频
- **合并**：合并多个视频片段
- **修剪**：修剪视频到指定时间范围

#### 效果操作
- **淡入**：添加淡入效果
- **淡出**：添加淡出效果
- **变速**：调整视频播放速度

## 技术实现

### 核心组件
- **VideoEditWidget**：主要的视频编辑界面组件
- **VideoProcessor**：基于MoviePy的视频处理引擎
- **ConfigManager**：配置管理器，保存用户设置

### 界面布局
- **左侧面板**：视频列表管理
- **中间面板**：视频预览和播放控制
- **右侧面板**：编辑操作工具

### 依赖库
- **PyQt5**：GUI框架
- **MoviePy**：视频处理库
- **OpenCV**：视频信息获取
- **NumPy**：数值计算支持

## 使用方法

### 1. 添加视频
1. 点击左侧面板的"添加视频"按钮
2. 在文件对话框中选择一个或多个视频文件
3. 视频将自动添加到列表中，显示文件名和时长

### 2. 预览视频
1. 双击视频列表中的任意条目
2. 视频将在中间面板中加载预览
3. 使用播放控制按钮或快捷键控制播放

### 3. 编辑视频
1. 加载要编辑的视频
2. 使用进度条定位到需要编辑的位置
3. 点击右侧面板的相应编辑按钮
4. 根据提示完成编辑操作

### 4. 导出结果
- 编辑完成的视频将自动保存到配置的输出目录
- 默认输出目录为项目根目录下的`output`文件夹

## 配置选项

### 视频编辑配置
- `video_edit.last_video_list`：上次使用的视频列表
- `video_edit.output_dir`：视频输出目录
- `video_processing.temp_path`：临时文件目录
- `video_processing.output_path`：处理结果输出目录

## 注意事项

1. **性能要求**：视频编辑需要较高的系统性能，建议使用配置较好的计算机
2. **文件格式**：支持主流视频格式，推荐使用MP4格式以获得最佳兼容性
3. **存储空间**：视频编辑会产生临时文件，请确保有足够的磁盘空间
4. **MoviePy依赖**：确保已正确安装MoviePy库，否则部分功能可能无法使用

## 故障排除

### 常见问题
1. **视频无法加载**：检查文件格式是否支持，文件是否损坏
2. **播放卡顿**：可能是视频文件过大或系统性能不足
3. **编辑功能不可用**：检查MoviePy是否正确安装
4. **快捷键不响应**：确保视频编辑界面处于焦点状态

### 日志查看
- 所有操作都会记录到日志中，可以通过日志查看详细的错误信息
- 日志级别包括INFO、WARNING、ERROR等

## 扩展开发

### 添加新的编辑功能
1. 在`VideoEditWidget`类中添加新的按钮和信号连接
2. 在`VideoProcessor`类中实现具体的视频处理逻辑
3. 使用MoviePy API完成视频操作
4. 更新界面和用户交互逻辑

### 自定义快捷键
1. 在`_setup_shortcuts`方法中添加新的快捷键定义
2. 连接到相应的处理方法
3. 更新用户文档
