# 改进版 PKL to FBX 转换器使用指南

## 概述

改进版 PKL to FBX 转换器 (`improved_pkl_to_fbx_converter.py`) 是对原始转换器的重大升级，旨在创建更符合Maya等3D软件标准的人体模型FBX文件。

## 主要改进

### 1. 完整的人体骨骼结构
- **20个骨骼节点**：包含完整的人体骨骼层次结构
- **骨骼层次**：
  - `Hips` (根骨骼)
    - `Spine` → `Spine1` → `Spine2`
      - `Neck` → `Head`
      - `LeftShoulder` → `LeftArm` → `LeftForeArm` → `LeftHand`
      - `RightShoulder` → `RightArm` → `RightForeArm` → `RightHand`
    - `LeftUpLeg` → `LeftLeg` → `LeftFoot`
    - `RightUpLeg` → `RightLeg` → `RightFoot`

### 2. 人体网格支持
- **网格创建**：基于PKL文件中的mesh数据创建3D网格
- **顶点数量**：支持6890个顶点的SMPL模型
- **面片生成**：自动创建三角形面片
- **缩放优化**：100倍缩放确保在Maya中正确显示

### 3. 蒙皮绑定
- **自动绑定**：网格自动绑定到骨骼
- **权重分配**：智能分配顶点权重到主要骨骼
- **变形器**：创建FBX蒙皮变形器

### 4. 动画支持
- **关键帧动画**：基于COCO 17关节数据创建骨骼动画
- **帧数优化**：智能采样减少文件大小
- **插值**：线性插值确保平滑动画

## 生成的文件信息

### 文件详情
- **文件名**：`improved_human_model_person_1.fbx`
- **文件大小**：约145KB
- **动画帧数**：81帧
- **骨骼数量**：20个
- **网格顶点**：6890个
- **格式版本**：FBX 2020.3.2

### 数据来源
- **关节数据**：COCO 17关节格式 (81帧 × 17关节 × 3坐标)
- **网格数据**：SMPL模型格式 (81帧 × 6890顶点 × 3坐标)
- **坐标系统**：右手坐标系，Y轴向上

## Maya导入指南

### 导入步骤
1. 打开Maya
2. File → Import → 选择 `improved_human_model_person_1.fbx`
3. 在导入选项中确保启用：
   - Animation
   - Deformed Models
   - Skins
   - Blend Shapes

### 预期效果
- **完整人体模型**：包含网格和骨骼的完整人体
- **骨骼层次**：清晰的骨骼父子关系
- **蒙皮绑定**：网格跟随骨骼变形
- **动画播放**：81帧的人体动作动画

### 显示设置
- 在Maya中切换到 "Smooth Shade All" 模式
- 启用 "X-Ray Joints" 查看骨骼
- 播放时间轴查看动画效果

## 技术特点

### 骨骼映射
```
COCO关节 → FBX骨骼
├── nose → Hips, Spine, Neck, Head
├── shoulders → LeftShoulder, RightShoulder
├── elbows → LeftForeArm, RightForeArm
├── wrists → LeftHand, RightHand
├── hips → LeftUpLeg, RightUpLeg
├── knees → LeftLeg, RightLeg
└── ankles → LeftFoot, RightFoot
```

### 坐标变换
- **缩放因子**：100倍放大
- **偏移调整**：脊椎、颈部、头部适当偏移
- **坐标系**：保持右手坐标系

### 网格处理
- **顶点位置**：基于第一帧mesh数据
- **面片创建**：连续顶点组成三角形
- **法线计算**：自动计算面法线

## 使用建议

### 最佳实践
1. **数据检查**：确保PKL文件包含joints3d和mesh数据
2. **文件路径**：使用绝对路径避免路径问题
3. **Maya版本**：推荐Maya 2020或更高版本
4. **预览设置**：导入后调整显示模式获得最佳效果

### 故障排除
- **网格不显示**：检查Maya的显示模式设置
- **动画不播放**：确保时间轴范围正确
- **骨骼太小**：调整骨骼显示大小
- **蒙皮问题**：重新绑定蒙皮或调整权重
